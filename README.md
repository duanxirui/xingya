# 星芽学堂 · 一至六年级教材同步学习平台

一个无需构建的本地网页学习平台。**当前开放一年级、二年级**的上、下学期课程，支持课前预习、课后复习、练习、单元测试、期中测试、期末测试、错题本和学习报告。**三至六年级暂时锁定**；其教材目录、学习内容和题库已保留，后续可以逐级开放。

## 教材来源与版本边界

本项目是独立的非官方学习工具。教材版本会随入学年级、学年更新；目前各册使用的目录基准**并非都是 2026 年最新版**。

| 对应册次 | 采用的目录或参考版本 |
| --- | --- |
| 一、二年级语文、数学上下册 | 2024 修订体系下相应年级、学期目录 |
| 三年级语文上册 | 2026 年秋季修订目录 |
| 三年级数学上册 | 人教 2024 修订版的单元目录（2026 年秋季使用） |
| 三年级语文、数学下册 | 旧版目录，必须与学校实际发放教材核对 |
| 四、五、六年级语文、数学上下册 | 以相应旧版单元顺序整理，学校版本须核对 |
| 三至六年级 PEP 英语（六年级下册除外） | 按人教社 PEP 修订教材的单元主题整理 |
| 六年级英语下册 | 暂按旧版 PEP 目录编排，修订版目录尚待确认 |

目录页展示每册的**具体版本标记与参考链接**，便于逐册核对。尤其是旧版教材册次，使用前请检查学校课本的封面、印次及目录。如果学校使用不同版本，应先替换对应数据，避免跨版混学。

主要核对入口：

- [人民教育出版社 · 小学英语 PEP](https://www.pep.com.cn/zslth/yyptzy/xypep/3s/)；其余英语册次的官方页面链接逐册收录在课程目录中。
- [三年级语文上册 2026 年秋季目录参考](https://www.dzkbw.org/book/4845.html)。
- [三年级数学上册 2024 年版目录参考](https://keben.app/book/0017)。
- [人民教育出版社 · 统编教材修订说明](https://www.pep.com.cn/bks/xxyw/jzjd/202507/W020250716532280620290.pdf)。
- 其他册次各自在数据文件和网页教材信息栏提供参考链接。

**内容说明：**平台的学习目标、讲解、课前问题、数学专题拆分、英语词汇训练、复习卡、选择题及解析为独立编写，不是教材逐页还原、课本原文、官方配套练习或正式考试真题。部分原创习题为基础概念和学习方法题，不能取代学校课堂作业与测试。

## 启动方式

在浏览器直接打开本文件夹的 `index.html` 即可。若安装了 Node.js，也可在本目录执行：

```powershell
node server.js
```

随后打开终端显示的本地地址（通常为 `http://127.0.0.1:4173`）。无需数据库、构建工具或外部 API；用户昵称、预习/复习记录和测试成绩保存于当前浏览器的 `localStorage` 中。清除浏览器站点数据会影响历史记录。

## 使用流程

1. 在顶部或侧边栏选择一年级、二年级与上/下学期；三至六年级显示锁定，无法切换。不同学期的进度与成绩分别统计。
2. **课程目录**：无需改变当前学习身份，可浏览已开放年级的上下学期内容，按学科、单元、标题搜索，打开条目阅读原创讲解；可展开答案，也能返回上一课/下一课。三至六年级目录入口暂不可用。
3. **课前预习**：按思考、学习、练习的步骤完成并记录进度。
4. **课后复习**：通过翻转知识卡回想学习内容并记录进度。
5. **测试与考试**：可进行教材学科随机挑战、课内练习、单元、期中和期末考试。答题后按 100 分制评分，显示解析，答错内容进入错题本。

新增 `data-question-expansion.js` 题库，目前新增 **6162 道原创练习题**，连同既有的课程题和阶段测试题，合计约 **8400 道**。扩充内容包括按年级和主题变化数字的数学计算与应用题、语文阅读理解与语言运用题、英语单元词义和补全句子题。题目按年级、学期、学科、单元归档；部分素材为基于单元主题编写的通用练习，并不代表出版社原题。

**每类阶段考试固定题数**：单元测试每次 **10 题**、期中每次 **20 题**、期末每次 **30 题**。无需选择题数，选择学科和单元后直接开始。每次开始考试均随机组卷，同一试卷内题干去重，期中、期末尽可能轮流覆盖各单元，并优先避开最近三次同学科阶段考试用过的题；只有当对应题池不足时才会复用旧题或减少题数。

期中按前半学期正式单元组卷，期末覆盖本册正式单元。考试过程中不立即公布答案，交卷时显示正确答案、解析、单元分析，并保存分数与已考题号，用于后续抽题避重复。**阶段考试范围为平台按单元估算，不代表学校确定的期中进度。**

## 代码结构与后续更新

| 文件 | 职责 |
| --- | --- |
| `index.html`、`styles.css` | 页面结构和响应式样式 |
| `app.js` | 交互、课程浏览、预习复习、组卷、评分、成绩存储 |
| `data.js` | 学科、年级、学期与 `openGrades` 开放范围的基础定义 |
| `data-pep-2024.js` | 一、二年级语文、数学的教材目录与原创导学 |
| `data-grade3-6.js` | 三至六年级语文、数学、PEP 英语的目录与原创导学 |
| `data-exams.js` | 一、二年级额外的原创考试题 |
| `data-question-expansion.js` | 一至六年级按单元生成的原创练习题、词汇题和阅读理解题 |
| `server.js` | 可选本地网页服务器 |
| `_smoke-test.cjs` | 不依赖浏览器的基础数据、预习、复习及考试回归检查 |
| `data-grade1.js` | 历史示例文件（当前页面**不加载**） |

每本教材数据包含 `grade`、`semester`、`subject`、`edition`、`sourceUrl` 和 `units`。更换教材版本时请核对课题、顺序、单元名称及相关知识点，并同步更新版本标记。新增学习主题沿用现有 `lessons` 格式；唯一的课程 ID 用于成绩关联，因此更新已发布课程时应保留未改变主题的 ID。

后续要开放三至六年级，只需修改 `data.js` 中的 `openGrades: [1, 2]`，将准备开放的年级 ID 加入数组，例如开放三年级可设为 `openGrades: [1, 2, 3]`。锁定只影响界面入口和访问范围，已写入的高年级课程、题库与浏览器学习记录不会因此被删除。

修改课程或考试逻辑后，可运行 `node _smoke-test.cjs` 检查已开放的 4 个年级学期组合、28 次模拟考试、锁定入口以及旧记录保留情况；同时检查全部 32 册教材和 1058 条课程的数据完整性。本检查模拟浏览器事件，不能替代真实浏览器下的视觉与兼容性检查。

> 内容建设状态：一、二年级已开放；三至六年级的数据目前仅作开发储备，用户界面暂时锁定。高年级大量内容为依照单元主题自动整理的原创初稿，**未达到逐页、逐课核对全部正式教材的精度**，正式开放前仍需逐册人工校审。
